# 私人记账本

一款**纯静态网页应用**，无后端、无数据库，支持 iPhone 和 Mac 访问，可部署到免费静态托管平台。

## 特点

- **纯静态应用**：无服务器依赖，直接上传部署
- **PWA 支持**：iPhone 可添加到主屏幕，全屏体验接近原生 App
- **数据本地存储**：使用 localStorage，数据保存在浏览器
- **跨设备同步**：通过导入导出 JSON 文件实现数据同步
- **免费部署**：支持 Vercel、Netlify、GitHub Pages 等平台

---

## 快速部署

### 方式一：Vercel 部署（推荐）

1. 访问 https://vercel.com 并登录（可用 GitHub）
2. 点击 "New Project"
3. 选择 "Upload" 方式，上传整个项目文件夹
4. 点击 "Deploy"
5. 获得永久访问链接（如 `https://your-app.vercel.app`）

**优点**：
- 自动 HTTPS
- 全球 CDN 加速
- 每次修改可重新上传更新

### 方式二：Netlify 部署

1. 访问 https://netlify.com 并登录
2. 点击 "Add new site" → "Deploy manually"
3. 拖拽整个项目文件夹到上传区域
4. 等待部署完成
5. 获得访问链接（如 `https://your-app.netlify.app`）

### 方式三：GitHub Pages

1. 在 GitHub 创建仓库
2. 上传项目文件
3. Settings → Pages → Source: main branch
4. 访问 `https://username.github.io/repo-name`

## 使用指南

### iPhone 端使用

#### 1. 访问应用
在 Safari 中打开部署后的链接

#### 2. 添加到主屏幕（重要）
1. 点击 Safari 底部的"分享"按钮
2. 选择"添加到主屏幕"
3. 命名为"记账本"
4. 点击"添加"

**效果**：
- 全屏运行，无浏览器地址栏
- 体验接近原生 App
- 可像普通 App 一样从桌面启动

#### 3. 记账操作
1. 设置周期：填写起始/结束日期和总预算
2. 记账：输入金额、备注、选择分类
3. 点击"记一笔"

#### 4. 导出数据（同步到 Mac）
定期点击右上角**导出按钮**（📥），下载 JSON 文件：
- 文件命名：`记账数据_2024-01-15.json`
- 包含全部记账记录和设置
- 保存到 iPhone 或发送到 Mac（AirDrop/邮件）

---

### Mac 端使用

#### 1. 导入数据
1. 在浏览器打开部署链接
2. 点击右上角**导入按钮**（📤）
3. 选择 iPhone 导出的 JSON 文件
4. 确认导入

#### 2. 查看数据
导入后可查看：
- 周期预算和剩余
- 全部消费记录
- 分类统计图表
- 每周消费分析

#### 3. 导出完整数据
点击导出按钮，下载 CSV 格式文件：
- 可用 Excel 打开
- 包含 ID、金额、描述、分类、日期等字段
- 用于数据分析或打印存档

## 数据同步方案

由于应用是纯静态（无后端），iPhone 和 Mac 的数据**默认独立存储**在不同浏览器的 localStorage 中。

### 同步流程

```
iPhone (日常记账)
    ↓ 定期导出 JSON
    ↓ AirDrop / 邮件 / iCloud Drive
Mac (导入查看)
    ↓ 导入 JSON
    ↓ 查看完整数据
    ↓ 导出 CSV
```

### 建议操作

- **iPhone**：日常记账，每周导出一次 JSON 文件
- **Mac**：导入查看，每月导出 CSV 存档
- **备份**：重要数据建议多处保存（云盘、邮件）

## 常见问题

### Q1: iPhone 数据和 Mac 数据如何同步？
A: 通过导入导出 JSON 文件手动同步。iPhone 导出 → Mac 导入。

### Q2: iPhone 换了浏览器，数据会丢失吗？
A: localStorage 是浏览器独立的。建议定期导出备份。

### Q3: 可以多人共享数据吗？
A: 可以通过发送 JSON 文件实现，但每次导入会覆盖当前数据。

### Q4: 为什么不用云数据库？
A: 为了保持纯静态、无后端，免费部署，无需任何费用。

### Q5: Chart.js 图表加载慢怎么办？
A: Chart.js 从 CDN 加载，首次加载可能稍慢。后续会缓存。

### Q6: PWA 添加到主屏幕后，如何更新？
A: 重新访问部署链接，浏览器会自动更新缓存。

### Q7: 数据存储在哪里？
A: 存在浏览器的 localStorage，位置：
- Chrome: 用户数据目录
- Safari: ~/Library/Safari/LocalStorage
- 建议定期导出备份

### Q8: CSV 导出的文件格式？
A: 包含字段：ID、金额、描述、分类、日期、创建时间，可用 Excel 打开。

## 注意事项

1. **数据备份**：定期导出 JSON 文件备份
2. **浏览器切换**：更换浏览器后数据需重新导入
3. **隐私安全**：虽然应用是公开链接，但数据在本地，他人访问无数据
4. **存储限制**：localStorage 通常限制 5-10MB，足够记账使用
